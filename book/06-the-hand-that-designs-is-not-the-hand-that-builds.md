# 6 · The hand that designs is not the hand that builds

**When the same agent designs and implements, constraints drift toward whatever was easiest to build. Separating the two makes the drift visible as a diff.**

**Scene to write:** Claims adjudication — an implementing agent relaxes a coverage-date check to make a failing test pass.

## To graduate

A drift caught by comparing the built shape against the designed one, and the line in the design that caught it.
